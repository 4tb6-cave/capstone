    %% Top Event Definition
    A[C.A.V.E. Safety Failure] --> C[Sensor Data Loss]

    %% Sensor Data Integrity Failure Branch (requires all sensors failing)
    C --> D(AND)
    D --> E[ToF Data Loss/Inaccuracy]
    D --> F[Lidar Data Loss/Inaccuracy]
    D --> G[IMU Data Integrity Failure]

    %% System Operation Failure Branch (any failure causes system issue)
    A --> H{OR}
    H --> I[Battery Failure During Exploration]
    H --> J[Data Processing Errors]

    %% Mechanical Design Failures Branch (multiple issues can cause problems)
    A --> K{OR}
    K --> L[Wearable Disruption]
    K --> M[Battery Safety Hazard]

    %% Specific failure paths
    E --> E1[Calibration drift in temperature]
    E --> E2[Dust/moisture accumulation]
    F --> F1[Low light visibility issues]
    F --> F2[Inadequate resolution for crevices]
    G --> G1[Gyroscope drift]
    G --> G2[Magnetic interference]

    I --> I1[Overestimation of battery capacity]
    I --> I2[Voltage regulation failure]

    J --> J1[Sensor fusion algorithm failures]
    J --> J2[Raspberry Pi overloading]

    L --> L1[Sensor position/orientation altered]
    L --> L2[Unbalanced weight distribution]

    M --> M1[Improper battery casing]
    M --> M2[Overheating in confined spaces]

    %% Mitigation nodes
    E --> |SPECIAL CASE FOR MITIGATION| X1[Data loss mitigation strategy]
    J --> |SPECIAL CASE FOR MITIGATION| X2[Error handling protocol]
